## 🃏 Acerca del Juego

**MUNO!** es una versión web multijugador en tiempo real del clásico juego de cartas UNO, adaptada para jugar desde el navegador en computadora o teléfono móvil. 

Incluye todas las reglas y cartas tradicionales (+2, +4, Cambio de Color, Reversa, Salto y el grito de **¡MUNO!**), optimizado para que las partidas sean rápidas, estables y divertidas entre amigos.

👉 **Juega en vivo ahora:** **[https://muno.macrostasis.dev](https://muno.macrostasis.dev)**

---

## 🔥 Lo Nuevo y Destacado

- 📱 **Diseñado para Celulares**: Interfaz táctil adaptada a pantallas móviles, chat dinámico y cartas ampliadas sin recortes.
- 🍪 **Reconexión Inteligente**: Si se te cierra la pestaña o entras desde un enlace en WhatsApp/Discord, te reconecta de inmediato a tu casilla y recuperas tus mismas cartas sin crear cuentas duplicadas.
- 🎯 **Robos Balanceados**: Límite de máximo 5 robos por turno si no tienes carta jugable para que la partida nunca se vuelva lenta.
- 🎒 **Límite de Cartas en Mano**: Máximo 30 cartas por jugador para mantener la pantalla limpia.
- ⚙️ **Expulsión por Inactividad**: Si alguien no responde durante 2 turnos seguidos, el servidor lo saca automáticamente y regresa sus cartas al mazo.
- 👑 **Cambio de Admin Automático**: Si el creador de la sala se desconecta, se le otorga el rango de Administrador al siguiente jugador en línea.

## 💻 Instalación y Ejecución Local

### 1. Clonar el repositorio
```bash
git clone https://github.com/MetaCodeX/muno.git
cd muno
```

### 2. Instalar dependencias
```bash
npm install
```

### 3. Ejecutar servidor y cliente
```bash
node server.js   # Inicia el backend
npm run dev      # Inicia el frontend
```
